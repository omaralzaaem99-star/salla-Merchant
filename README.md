# Salla Merchant — سلة للتجار

سورس تطبيق المتجر الحالي **1.0.1+28**، المبني على سورس شركة النشر مع آخر تعديلات الاستكشاف وإنشاء الحساب وانتظار موافقة الإدارة.

## المحتويات

- `sala_store`: تطبيق المتجر لأندرويد وiOS مع الأصول والاختبارات.
- `packages/salla_auth` و`packages/salla_data`: الحزم المحلية اللازمة لتشغيل المتجر؛ أبقها بجانب مجلد التطبيق.
- `SOURCE_MANIFEST.json`: بصمات ملفات السورس للتحقق من تطابق التسليم.

لا يتضمن هذا المستودع تطبيقات الإدارة أو السائق أو الزبون، ولا وظائف الخادم أو بيانات المستخدمين أو مفاتيح التوقيع. إعدادات Firebase المرفقة إعدادات عميل التطبيق.

## التشغيل

النسخة اختبرت باستخدام Flutter 3.44.0 / Dart 3.12.1. افتح جذر هذا المستودع في VS Code، ثم:

```sh
cd sala_store
flutter pub get
flutter run --flavor prod --dart-define=SALLA_ENV=prod --dart-define=SALLA_DATA_BACKEND=firebase
```

الأمر أعلاه لأندرويد. معرّف إنتاج Android: `com.salasala.marchent`. معرّف iOS: `com.salllla.marchent`.

إصدار Android الموقّع يتطلب ملف التوقيع المحلي `~/.selafood/signing/store.properties` ومفتاحه؛ غير مرفقين بالمستودع. بناء iOS والتوقيع يتطلبان macOS وXcode وإعداد حساب النشر.

## الحسابات

الضيف يستكشف الصفحة الرئيسية دون بيانات تشغيلية. إنشاء الحساب بالاسم والهاتف والعنوان يرسل طلباً إلى خدمة Firebase القائمة. الإدارة تكمل بيانات المتجر ثم تضغط **الموافقة وتفعيل الحساب** من **طلبات انضمام المتاجر**. تشغيل المتجر وحده لا يكمل موافقة الحساب. يفتح الحساب من هاتف التقديم بعد الموافقة؛ الدخول من هاتف آخر برقم الهاتف ورمز الإدارة.

الخادم وقواعده ولوحة الإدارة اعتماد خارجي قائم وليست جزءاً من هذا المستودع. راجع [تفاصيل التسليم](README_COMPANY_AR.md).
